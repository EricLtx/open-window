# Open Window

An on-chain repo contract on Stellar. Holders of tokenized money market funds borrow stablecoins against their shares at any hour, for a fixed term and a fixed price, when the fund's redemption window is closed.

> **Status:** hackathon build. Code in this repository starts on 25 October 2026; nothing here predates the event. Framing and feasibility documents are kept privately and are not part of this repository.

## Layout

Code is added here as it is written. Framing documents live in numbered local folders (`01_Strategie` to `11_...`) that are ignored by git.
